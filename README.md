# Personal Portfolio

Static site: HTML, CSS and vanilla JavaScript. No build step.

## Edit
- Search every file for `[` and `YOURNAME`, `YOUR-USERNAME`, `your.email@example.com` and replace with your details.
- Replace `images/profile.svg` with your photo (keep the name, or update the `src` in index.html). Use JPG/WebP under 150 KB.
- Replace `images/project-1.svg` etc. with screenshots (about 1200x720 px, WebP or JPG).

## Run locally
Double-click `index.html`, or run `python -m http.server 8000` in this folder and open http://localhost:8000.

## Deploy
Push to GitHub, then connect the repo in Cloudflare Pages (build command empty, output directory `/`).
